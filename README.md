# Lucille's Journey

An empathy-focused 2D pixel-art narrative game about Lucille, a refugee mother, built in Unity 6 (6000.3.8f1, URP 2D).
Built for GADS6222 in collaboration with UXTE7312, for The Refugee Archive.

## Run it
1. Open the project folder in Unity Hub with Unity **6000.3.8f1**.
2. Open `Assets/Scenes/MainMenu.unity` and press Play (or open any chapter scene to jump straight in).

If you change the journey definitions in `Assets/Scripts/Gamification/JourneyCatalog.cs`, run **Lucille's Journey > Build All** to regenerate the scenes and data assets. **Lucille's Journey > Validate Journey Catalog** checks ids, sprites and narrative assets.

## Controls
Move: WASD / arrows / left stick. Interact: E / Space / gamepad A. Pause: Esc. Quest Journal: J. Memory Album: M. Keepsakes: K. Switch journal section: Tab.

## Project layout
- `Assets/Scripts/Core` - progress, save system, settings, chapter flow
- `Assets/Scripts/Gamification` - journey catalog, stats, achievements, and the pixel-art UI (`UI/`)
- `Assets/Scripts/Audio` - music, ambience and world sounds
- `Assets/Resources/JourneyUI` - pixel-art sprites; `Resources/Audio` - music and effects; `Resources/Fonts` - pixel fonts
- `Assets/Editor` - scene builders, validators and the automated Play Mode test (`JourneyPlayTests`)
- `Tools/PixelArt`, `Tools/AudioGen` - .NET tools that generate the sprites and audio (run with `dotnet run -c Release --project Tools/<name>`)
- `Tools/WorldArt` (Chapter 1) and `Tools/WorldArtCh2` ... `Tools/WorldArtCh6` - generate each chapter's overworld: baked ground, props, depth-sorted layout JSON in `Assets/Resources/World`. Artist-made art can later replace any of these sprites by name; the layout files only reference sprite names, and Lucille depth-sorts against every prop by her feet.

## Saves
Progress is one JSON file in the Unity persistent data path, with a `.bak` backup. Use **Lucille's Journey > Save > Back Up and Reset Progress** for a safe test reset.
